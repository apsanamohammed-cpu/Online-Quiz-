# Online Quiz Application

A simple Online Quiz Application developed using Java, HTML, Java Servlet, Maven, and Apache Tomcat.

## Features

- Multiple-choice quiz questions
- User-friendly quiz interface
- Automatic score calculation
- Java Servlet backend
- Maven project structure
- Runs using Apache Tomcat

## Technologies Used

- Java
- HTML
- Java Servlet
- Maven
- Apache Tomcat

## How to Run

1. Build the project using Maven.
2. Start the application using Apache Tomcat.
3. Open the application in a web browser.
4. Answer the quiz questions and submit the quiz.
5. View the final score.

## Project Structure

- `quiz.html` – Quiz user interface
- `QuizServlet.java` – Java Servlet backend
- `pom.xml` – Maven configuration
- `README.md` – Project documentation
